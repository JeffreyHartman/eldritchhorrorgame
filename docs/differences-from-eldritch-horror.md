# Differences from Eldritch Horror

All core systems have been migrated to match the Eldritch Horror base game rulebook:

| System            | Status                                                                 |
| ----------------- | ---------------------------------------------------------------------- |
| Skills            | Matches Eldritch Horror: Lore, Influence, Observation, Strength, Will  |
| Skill tests       | Matches Eldritch Horror: 1 Clue rerolls 1 die; highest +bonus + extra dice; Blessed (4+) and Cursed (6) |
| Actions           | Matches Eldritch Horror: Travel, Rest, Trade, Prepare for Travel, Acquire Assets, Component actions |
| Travel            | Matches Eldritch Horror: Train and Ship Tickets (max 2), Uncharted/Train/Ship paths on the 36-space map |
| Assets            | Matches Eldritch Horror: Acquire Assets tests Influence against Reserve card values; Bank Loan / Debt |
| Clues             | Matches Eldritch Horror: gained from Research encounters at Clue tokens and spent on rerolls, Mysteries, and Rumors |
| Combat            | Matches Eldritch Horror: Will test (horror - successes = Sanity loss), Strength test (damage - successes = Health loss and wounds dealt) |
| Mythos            | Matches Eldritch Horror: 3-stage deck (green, yellow, blue) per Ancient One; 7 Mythos order elements including Reckoning, Rumors, Ongoing cards, and Eldritch tokens; empty Mythos deck loses |
| Omen track        | Matches Eldritch Horror: 4-space track (green, blue, red, blue); advances Doom for matching Gates |
| Doom              | Matches Eldritch Horror: advances from Omen/Gates, Defeats, and card effects |
| Gates             | Matches Eldritch Horror: colored Gates (green, blue, red), closed via Other World encounters and effects |
| Mysteries         | Matches Eldritch Horror: 1 active Mystery at a time from the Ancient One's deck; solve 3 (plus Final Mystery if awakened) |
| Encounters        | Matches Eldritch Horror: Americas, Europe, Asia/Australia, General, Other World, Research (per Ancient One), Expedition, Rumor, and Defeated Investigator encounters |
| Conditions/Spells | Matches Eldritch Horror: double-sided cards with hidden backs that flip on Reckoning or casting |
| Awakening         | Matches Eldritch Horror: Azathoth devours the world immediately; Yog-Sothoth, Shub-Niggurath, and Cthulhu flip to their Final Mystery |
| Defeat            | Matches Eldritch Horror: advances Doom by 1, relocates token to nearest City for Crippled/Insane encounter, chooses replacement at end of Mythos Phase before awakening |
| Player count      | Matches Eldritch Horror: 1 to 8 investigators, Reference Card table for Gates, Clues, and Monster Surge, Lead Investigator token, and Active Expedition token |
